# System Prompt Review

## Purpose

Review the System Prompt against the most important customer scenarios before implementing the voice agent.

The goal is to identify logical gaps before testing on a real voice platform.

---

# Review 01 — Happy Path

### Customer
"I have a residential house. I own it myself, the original documents are available, I need 50 lakhs, I'm salaried, my salary comes into my bank account, the property is worth around 1 crore, and I want a 10-year tenure."

### Expected State

property_type = RESIDENTIAL
ownership_status = SOLE
documents_available = YES
loan_amount = ₹50,00,000
occupation = SALARIED
income_mode = BANK
market_value = ₹1,00,00,000
tenure_years = 10

### Expected Outcome

QUALIFIED

### Prompt Check

The prompt instructs the agent to extract multiple pieces of information from a single customer utterance.

Result:

PASS

# Review 04 — Above ₹75 Lakh

### Customer
"I need ₹90 lakh."

### Expected Behavior

Agent explains that the maximum available under this offer is ₹75 lakh.

Agent asks whether the customer wants to proceed with ₹75 lakh.

### If Customer Says

"Yes."

Expected:

loan_amount = ₹75,00,000

Continue qualification.

### If Customer Says

"No."

Expected:

End conversation.

### Prompt Check

The prompt explicitly handles amounts above ₹75 lakh.

Result:

PASS

# Review 05 — Existing Loan

### Customer
"I already have a loan on this property."

### Expected State

existing_loan = YES

status = TRANSFER_REQUIRED

### Expected Outcome

Transfer to specialist.

Do not continue fresh-loan qualification.

### Prompt Check

Transfer is explicitly checked before ordinary qualification.

Result:

PASS
